# Finance Reports

Учебный веб-сервис формирования финансовой отчётности по заказам интернет-магазина.

Проект выполнен в рамках практики и не предназначен для обработки реальных финансовых операций, реальных персональных данных и реальных платёжных реквизитов.

## Возможности

- авторизация пользователей;
- роли: администратор, старший финансист, финансист-практикант;
- маскирование чувствительных данных для роли практиканта;
- просмотр заказов;
- просмотр платежей и возвратов;
- сводный отчёт;
- отчёт по дням;
- отчёт по способам оплаты;
- отчёт по возвратам;
- отчёт по частичным возвратам;
- отчёт по заказам;
- экспорт отчётов в CSV для администратора и старшего финансиста;
- минимальный журнал аудита.

## Технологии

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Jinja2
- Bootstrap
- Passlib / bcrypt
- itsdangerous

## Запуск

Создать виртуальное окружение:

```bash
python -m venv .venv


Активировать окружение:
Для Windows:
.venv\Scripts\activate


Для Linux/macOS:
source .venv/bin/activate


Установить зависимости:
pip install -r requirements.txt


Запустить приложение:
uvicorn app.main:app --reload


Открыть:
http://127.0.0.1:8000



Тестовые учётные записи:
admin Admin123! Администратор
senior Senior123! Старший финансист
intern Intern123! Финансист-практикант


Важно!!!
Все заказы, клиенты, платежи и возвраты являются синтетическими.
Оплата имитируется.
Реальные данные не используются.
Полные номера банковских карт не хранятся.
